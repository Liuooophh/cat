# 语音聊天（v6.11）

在基础设置的“语音”中配置腾讯云 SecretId、SecretKey，保存到 Windows 凭据管理器。现有 AI 接口配置继续使用；语音识别不是 AI 服务本身。程序不购买资源包、不开通付费服务，不修改腾讯云的后付费开关。凭据和录音不写入源码或发布包；本轮不自动上传 GitHub。

## 使用

- 点击聊天窗口话筒，或将鼠标移近猫咪后点击快捷话筒。仅点击后才录音；最长 55 秒，上传到腾讯云识别。
- 默认开启“说完自动发送并朗读 AI 回复”：完整识别结果进入当前对话，AI 回复使用已选音色播放。普通文字输入仍可手动发送，普通文字回复的自动朗读默认关闭。
- 快捷话筒不打开聊天窗口，复用同一份 history 和现有 AI 接口。聆听、识别、思考、播放时显示状态；再次点击快捷话筒或 × 取消。取消不会删除已发送的上下文，但会阻止迟到结果自动发送或播放。
- 普通聊天话筒的第二次点击是结束录音并提交；关闭聊天窗口会取消。关闭自动发送后，识别文字只填入输入框，供检查后手动发送。快捷话筒始终使用自动模式。
- 一句话识别接口没有可配置的流式 VAD 结束参数，所以继续复用现有本地录音能量检测。连续静音 2.2 秒才结束，短暂停顿不提交；无语音不上传，重复回调只接受一次。嘈杂环境及非常轻声的收音仍需实际麦克风验证。
- 目前按中国大陆使用场景接入；中、英、马来语识别均可选，当前朗读音色支持中英文，马来语保留文字。不承诺已验证海外调用。
- v6.7 快捷话筒采用选定的奶油陶瓷猫耳素材。原图由内置图像生成工具生成，保存在 assets/ui/cream-cat-microphone.png；设计提示为“奶油陶瓷猫耳话筒，正视，透明背景，清晰浅紫话筒符号，细腻倒角与轻阴影，无文字”。显示时采用 Lanczos 缩小及原有 Windows 逐像素透明方法，保留半透明边缘，不使用透明色键。悬停期间位置固定，卡片展开不移动按钮，不抢占前台焦点。
- 右键猫咪或托盘选择“隐藏猫咪”会取消语音并隐藏控件；点击托盘默认操作“显示猫咪”恢复。动画暂停，睡眠状态与聊天上下文保留；不会记忆隐藏状态到下一次启动。
- v6.8 首次启动使用独立 Tk 鼠标检测，首次映射后提交透明画面；短暂创建错误按 1～15 秒退避重试，不再永久停用话筒。录音时柔和光圈和五格音量条使用现有录音 RMS 能量，后台只维护线程安全的 0～1 音量值，结束/取消/错误时清零。安静时的轻微呼吸代表“正在聆听”；识别、思考、合成的转动提示及播放呼吸是状态动画，不代表识别进度或播放音频的真实音量。
- v6.11 缩短语音状态卡片，主文字按 12 像素、次提示按 11 像素抗锯齿绘制；第二行使用完整行宽，中英马短提示均可完整显示，长错误仍以省略号收尾。
- v6.10 将描边光圈替换为图案下方的模糊暖粉光晕，去掉右下角的圆形停止徽标与方块，不再遮挡猫耳图案。录音时保留五条真实音量声纹；识别、思考、合成使用依次亮起的底部三点，播放只保留呼吸光晕。快捷提示固定为两行，中文聆听状态为“正在聆听…”与“说完自动发送 · 再点取消”；英文与马来语也使用相应短提示。完整聊天窗口的手动结束录音行为保留。

## 验证边界

测试覆盖短暂停顿、取消后的迟到结果、空结果、重复回调、无聊天窗口的上下文、语音回复强制播放、手动输入、音色保存、天气配置跨重启保存及 Tk 变量回收。测试使用模拟 SDK/合成录音；不等同于真实麦克风或人工听感验收。此前 v6.4 曾完成真实腾讯云“你好”合成与识别，本轮不将旧结果冒充新交互的实测。

单独检查打包组件（不录音、不播放、不读取密钥、不访问云端）：

```powershell
.\PawpalCat-v6.11-Onefile.exe --speech-diagnostics .\speech-components.json
```

如自行加 `--live`，将读取已保存凭据并进行两次短云端调用，可能使用服务额度。
