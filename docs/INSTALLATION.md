# 安装版与直接运行版（v6.11）

安装版 PawpalCat-v6.11-Setup.exe：安装到当前用户的固定目录，默认是
%LOCALAPPDATA%\Programs\PawpalCat；包含完整程序、桌面/开始菜单快捷方式及卸载入口。
更新或卸载前请从托盘退出猫咪。安装程序会检测同一用户正在运行的桌宠，不强制关闭它。
安装桌宠本身不需要管理员权限；设置与凭据继续保存在原位置，不打包进入发行文件。

直接运行版 PawpalCat-v6.11-Onefile.exe：无需安装，可直接双击运行；它沿用便携版自启动管理，
不附带驱动安装器。首次运行需要解包依赖，因此比安装版启动稍慢。

## 大小基准

新版显示 100% 时，实际大小等于旧版 85%；新用户初始大小和“恢复默认”都显示 100%。
调节范围仍显示 50%～150%。旧配置换算到新基准，旧版保存的 85% 会显示为新版 100%；
超出新范围的历史值按边界限制。版本标记防止每次启动重复换算。

## 可选温度组件

安装向导检测组件，仅在缺失时显示相应安装选项，默认不勾选：

- PawnIO 2.2.0：附带原样的官方签名安装器。勾选后单独请求管理员授权并显示其安装提示。
  未勾选、拒绝授权或安装失败时，桌宠仍可使用，CPU 温度可能显示不可用。
- .NET Framework 4.8：附带微软官方签名的联网安装器。系统已有 4.8 或更高则跳过；
  缺失且选择补装时需要网络及管理员授权。使用微软自身安装界面及许可，不强制重启。

PawnIO 使用官方签名版，不使用 unrestricted 模式，不更改内存完整性或安全设置。
已有 PawnIO 不重复安装。即使安装完成，硬件兼容性和运行权限仍可能影响温度读取；
驱动默认访问控制下，部分电脑可能需要用户自行选择以管理员身份运行桌宠。
没有安装 LibreHardwareMonitor 主程序的必要。

选项跳过后，也可手动运行安装目录 Prerequisites 中的官方安装器。
卸载桌宠不会自动卸载 PawnIO 或 .NET，因为其他软件可能也在使用；也不会删除用户配置
或 Windows 凭据。卸载只清理仍然指向当前安装目录的本软件自启动入口。
安装版自启动直接指向固定安装目录，不再复制另一份桌宠。

静默安装与 /QA=1 验收模式不启动可选组件、不弹驱动 UAC；QA 模式也不修改既有自启动。

## 构建和检查

```powershell
python tools/build_windows.py --onedir --name PawpalCat --output-dir build/installer-payload
python tools/build_installer.py --prerequisite-cache ../installer-tools
python tools/build_windows.py --onefile --name PawpalCat-v6.11-Onefile
```

编译器使用 Inno Setup 6.7.3。前置组件来源及固定 SHA-256 位于
packaging/windows/prerequisites.lock.json；打包前还验证 Authenticode 签名及发布者。
官方安装器不做修改。第三方声明、编译器许可及中文翻译署名保存在 packaging/windows/。

针对性验证不等于在全新系统安装驱动成功。发布报告会区分：代码与模拟检查、真实安装/卸载、
打包后的诊断、缺少运行时的补装分支以及真实 CPU 温度读取。

v6.9 的 39 项大小基准、旧设置迁移、Tk 大小窗口、自启动和快捷话筒相关检查通过。
