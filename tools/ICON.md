# Cat app icon

Generated with the built-in imagegen tool, then converted to the application's
existing icon formats. No animation assets were changed.

- `pet_icon.png`: transparent RGBA, 256 × 256; used by the tray and settings header.
- `pet_icon.ico`: 16, 20, 24, 32, 40, 48, 64, 128 and 256 px; used by Windows,
  child-window title bars and the PyInstaller EXE resource.

Final generation prompt:

> Use case: logo-brand. Asset type: finished Windows desktop app icon for Pawpal Cat, a quiet realistic silver tabby desktop companion. Create ONE simple polished cat head icon on a truly transparent background. Front-facing rounded silver-gray tabby cat head with two small ears, ivory muzzle, clear warm golden eyes, a tiny soft charcoal nose and subtle forehead tabby stripes. Elegant softly shaded flat illustration with clean strong silhouette, carefully simplified for a 16x16 Windows system tray icon. Head fills about 88 percent of square canvas, centered; no full body, no badge, no square background, no accessories, no lettering, no watermark. Restrained warm gray, cream, charcoal and golden eyes; subtle muted lavender accent only if helpful. Crisp recognizable contour, avoid hairline detail and photoreal fur. Deliver a single large square transparent PNG icon.
