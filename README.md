# 熊大

一个面向 Windows 的桌面宠物程序。现在包含可拖动、逐像素透明的熊角色，多种动作、低频自主行为、鼠标互动和漫画气泡；原有聊天、AI 设置、右键菜单和系统托盘仍然保留。

## 启动

本仓库包含源码与运行所需素材，不包含预编译的 exe、构建缓存或本机配置。Windows 上安装 Python 3 后，可在项目目录运行：

```powershell
py -m pip install Pillow pystray
pyw .\desktop_ai_pet.pyw
```
## 操作

- 左键点熊：只触发一次角色互动，不打开聊天窗口；右键菜单选择“和熊大聊天”即可打开聊天窗口。
- 短时间连续点击会逐步增加吐槽强度；连续点到第五次会生气并进入短暂冷静时间。
- 按住左键拖动可以移动桌宠；桌宠不会被拖出屏幕。
- 右键熊或托盘图标可聊天、设置 AI 接口、调整大小或退出。
- 在“调整桌宠大小”中可拖动滑块实时预览，范围为 50%–150%；点“完成”后会记住大小。
- 待机默认先显示大笑姿势，并持续约 3–4 分钟；随后放松约 1–1.5 分钟，再平滑切回大笑。现有眨眼素材只会配合大笑姿势显示，避免待机时突然跳成大笑。桌宠每隔一段随机时间还会尝试发呆、打哈欠、走动、挥手或休息；大约三分钟没有互动后，更容易进入睡觉状态。自主动作带概率和冷却，不会固定几秒循环一次。
- 鼠标停在熊身上会偶尔出现互动气泡。动作台词气泡会自动换行、跟着桌宠移动，并在数秒内淡出。
- 待机且没有台词时，熊大头顶的气泡会显示时间、天气和 CPU 状态；互动台词出现时状态气泡让位，台词结束后再显示。

## 天气、系统状态和语音

从右键菜单或系统托盘打开“陪伴与语音设置”：

- 可填写城市以显示天气并触发低频天气反应；留空即可关闭天气查询。天气每小时更新，使用 Open-Meteo 的地理编码和预报服务；只有填写的城市名称会发送给该服务。
- 聊天窗状态栏也显示本机时间、天气和 CPU 使用率。CPU 与时间数据只在本机读取，高负载或深夜时熊大可能会说一句。
- 聊天窗麦克风支持中文语音输入，识别由 Windows 本机完成；说完停顿一下，识别结果会放入输入框供你检查，不会自动发送。
- 中文语音回复只使用当前播放接口可识别的中文男声，不会悄悄改用女声。此电脑的康康男声属于 Windows 新语音接口，当前版本无法调用；因此语音回复暂不可用。语音可以在设置中关闭。

## 增加角色动作图片

运行时帧图按动作放在 `assets\pet\<动作名>\`，使用透明背景 PNG，并按顺序命名为 `01.png`、`02.png` 等。程序启动时会自动加载文件夹里的帧；同一动作有多张图时会根据动作帧率播放。现在使用的动作目录包括：

`idle`、`blink`、`walk`、`happy`、`angry`、`laugh`、`yawn`、`sleep`、`clicked`、`surprised`、`confused`、`wave`、`interaction`。

自主走动使用 `walk` 中的多帧图；左右移动时会自动翻转角色。其它情绪会在进入状态时选一张对应姿势，`sleep` 会慢速轮播休息帧。

拆分当前动作表的脚本在 `tools\extract_bear_sprites.py`，两张原始表保存在 `assets\source\`。脚本会一并清理角色脚下分离的素材底边残线，并保留与角色分开的黄色强调图案。以后有新动作素材时，可把帧图直接放到相应动作文件夹；如果要从新的排版动作表批量切图，再调整这个脚本中的动作表位置。

## 增加台词

台词与 UI 分离，集中在 `pet_dialogue.py` 的 `DIALOGUE` 字典里。给相应动作列表追加新字符串即可；`DialogueManager` 会随机选择、避免同类台词连续重复，并根据文字长度估算显示时间。动作冷却在同一文件的 `COOLDOWNS` 中调整。

自主行为的检查间隔、出现概率、状态优先级和持续时间在 `pet_behavior.py` 中；PNG 加载、帧率和气泡绘制在 `pet_presentation.py` 中。

## 接入 AI

默认模型为 GPT-5.6 Sol，接口地址为 `https://api.openai.com/v1`。右键桌宠或托盘图标，选择“设置 AI 接口”，选定服务商并填写 API 密钥后保存即可。

- API 密钥保存在当前 Windows 用户的凭据管理器中，不写入设置文件；留空保存会删除已存密钥。
- AI 对话使用熊大的原创人格设定：憨厚、贪吃、懒散、调皮、爱吐槽又讲义气；不套用影视作品台词或剧情。
- OpenAI API 按用量单独计费，ChatGPT Go 订阅不包含 API 额度。程序会以较低推理档请求 Sol，并把单次回复限制在 512 个 token。
- DeepSeek 可在服务商选择框中选取，程序会自动填入官方接口 `https://api.deepseek.com` 和模型 `deepseek-flash`；请求使用 `/chat/completions` 路径，并把回复限制在 512 个 token。
- 也可以选“自定义 / Ollama”：Ollama 接口地址可填 `http://localhost:11434/v1`，模型名称填写本机已安装的模型。
- 接口地址和模型名保存在 `%APPDATA%\TuanziDesktopPet\settings.json`。发送的聊天内容会交给设置的接口服务商。

## 检查

在项目目录运行：

```powershell
py -m unittest discover -s tests -v
```

`tests\test_pet_core.py` 检查台词、防重复与点击升级、低频和系统状态反应、天气数据解析、CPU 采样、待机大笑优先与姿势淡化、PNG 帧、底边残线、大小范围和气泡淡入淡出。
