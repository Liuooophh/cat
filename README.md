# 猫咪 · Pawpal

面向 Windows 的透明桌面猫咪。新版使用五段 MP4 动画，保留聊天、拖动、右键菜单、系统托盘、大小调节和 AI 接口设置。

## 使用

便携版：先退出旧版，解压完整目录后双击 PawpalCat-v6.3.exe；保留旁边的 _internal 目录，不要只复制 EXE。也可使用单文件版。发布包不需要另装 Python，温度功能需要 Windows x64 与 .NET Framework 4.8 或更高版本。右键猫咪或托盘图标可以退出。

源码版：Windows x64、CPython 3.10–3.13（本轮使用 3.12.14），在项目目录执行：

```powershell
py -m pip install -r requirements.txt
pyw .\desktop_ai_pet.pyw
```

- 按住猫咪拖动；空闲时单击会播放一次抬爪互动，默认不发声，也不会弹出聊天窗口。
- 每 30–70 秒检查一次，大多数时候保持安静；偶尔洗脸或吃猫粮。
- 没有与猫咪互动约 3–5 分钟后，更容易睡觉。睡眠持续到单击或菜单唤醒；拖动和聊天不会唤醒。稳定睡眠使用原视频中的轻微呼吸，并叠加清晰的 zzz。
- 右键猫咪或托盘，可指定点击互动、吃猫粮、洗脸、睡觉和唤醒。前三种动作完整播放一次后回待机；其他请求最多排队一个。
- 右键选择“和猫咪聊天”可主动聊天，默认回复简短、温和。
- 视频音轨不播放。朗读功能已移除，CPU 和深夜主动提醒默认关闭。数据气泡默认在稳定待机和睡眠时显示，可在通用设置关闭。
- 气泡只展示时间、天气、系统 CPU 利用率和前台 FPS；优化分层合成、字体、留白和轻阴影，保持紧凑三行（关闭 FPS 时两行）。睡眠 zzz 加大加粗、增加描边并持续可见，与气泡留出距离。
- CPU/GPU 温度只在托盘与主动聊天查询中显示。原猫咪托盘保留，另有双行数字图标：上方绿色 GPU、下方琥珀色 CPU；多设备各组取最高有效值，悬停和菜单分别列出每个设备与来源。没有数据时显示 --，可在通用设置关闭温度托盘。
- 天气设置支持多结果城市选择、保存坐标和立即测试；每15分钟更新，失败保留并标记上次数据。城市留空时不查询天气。
- 系统 CPU 每秒用 Windows PDH 的整机总计数器采样，优先采用本机 Windows 22621 对应的 Processor Utility，并记录 Processor Time 与回退来源；过期快照不保持显示。不同 Windows 任务管理器版本可能采用不同口径，详见 [CPU 采样说明](docs/CPU_USAGE.md)。FPS 用随包 PresentMon 2.6.0 获取前台应用实际显示帧率，不能采集时显示状态。CPU、GPU 温度通过随包 LibreHardwareMonitorLib + pythonnet 在后台约每 1.5 秒读取，不需要打开 LibreHardwareMonitor 图形程序；无有效读数显示 --°C。
- CPU 优先 Package，替代来源会标明 Tdie、Tctl、Core Max 等；GPU 优先 Core，各张显卡按设备标识独立显示，不把显存或 Hot Spot 当成核心温度。部分 CPU 读取需要已有 PawnIO 驱动及适当权限；程序不安装驱动、不提权、不修改安全设置。详见 [温度说明](docs/TEMPERATURE.md)。
- 通用设置支持简体中文、English、Bahasa Melayu，即时切换并保存。
- v6.1 基础设置采用浅色卡片与开关样式；读数及自启动说明收进帮助按钮，设置较多时可滚动。窗口、托盘和 EXE 使用统一的银灰猫头图标，包含 16–256 像素的 ICO 尺寸。
- v6.2 修正爪子、尾巴与睡姿下方的白色底座：离线识别并清除浅灰影棚地面，保持现有 MP4、透明窗口、播放时序和界面。
- v6.3 将脚边的地面识别改为渐变阈值，清除右爪外侧残留的白色尖角，避免水平清理分界留下突起；继续复用原有 MP4 和透明渲染。
- 麦克风使用 Windows 本机中文识别，结果只填入输入框，检查后手动发送；不会自动发送或上传原始录音。
- 大小调节范围为 50%–150%。新用户默认 130%，已有设置保留原比例。

## 动画与资源

运行素材位于 assets/cat/，包含待机、点击互动、吃猫粮、洗脸和睡觉五段 MP4。每个 640×300 视频帧的左半边保存颜色，右半边保存透明度；运行时合成为 320×300 RGBA，再交给原有的 Windows 逐像素透明窗口。无需 PNG 序列，也不会在用户电脑上实时抠图。

播放器按时间选择帧，使用最多 96 张的解码缓存。缺失的情绪动作继续显示待机画面。所有动作都是 24 fps，保持统一比例、画布和地面位置；视频音轨在素材转换时已移除，程序只解码画面。

- 待机：240 帧整段循环，循环接缝使用 4 帧预乘透明度混合。
- 点击互动：96 帧完整播放一次，然后平滑回到待机。
- 吃猫粮：240 帧完整播放一次，猫粮道具包含在透明画面中，然后回到待机。
- 洗脸：240 帧完整播放一次，然后回到待机。
- 睡眠：入睡 [0,144)，轻微呼吸循环 [144,168)，醒来 [168,240)。睡眠不会超时；明确唤醒时完成当前呼吸循环后播放醒来段。

以上范围从 0 开始，包含左端且不包含右端。单次动作的首尾都回到坐姿，返回待机再使用约 0.22 秒的缓动混合，减少姿态切换时的闪动。

tools/prepare_video_assets.py 负责离线白底抠像、去白边、统一落点并生成颜色与透明度合装的 MP4。它只在重建素材时需要 OpenCV、NumPy、SciPy 和 FFmpeg；发布程序不包含这些 Python 包。运行时只带一个固定版本的 OpenCV FFmpeg VideoIO DLL，来源、哈希和许可证位于 assets/vendor/opencv-videoio/。旧 PNG 导入和处理工具仅保留给历史素材，不参与当前猫咪运行或打包。

旧熊素材 assets/pet/ 和切图工具保留在源码包中用于兼容性测试，猫咪程序不加载它们。

## AI、设置与数据

右键“设置 AI 接口”可配置 OpenAI、DeepSeek 或兼容接口，并通过同一请求路径测试连接；显示经过脱敏的具体错误。不同服务商分别保存配置，密钥保存在当前 Windows 用户凭据管理器中，不写入设置文件。留空保存会删除对应密钥。聊天询问天气或系统状态时优先读取本机查询数据。

DeepSeek 官方地址使用 https://api.deepseek.com 或 /v1，当前默认 deepseek-flash；旧 deepseek-chat/deepseek-reasoner 配置会迁移。普通聊天关闭默认高强度思考，连接测试限制输出 16 tokens。网络请求使用 Windows/环境代理及按网址解析的 PAC，保留 TLS 校验，不在代理失败时偷偷直连。天气保留成功预览并在保存后立即使用；失败提供具体 HTTP/网络原因。详见 [网络说明](docs/NETWORK.md)。

设置路径沿用 %APPDATA%\TuanziDesktopPet\settings.json。环境变量 PAWPAL_DATA_DIR 可指定独立验收目录，并跳过自启动注册。首次正常运行打包版本时默认启用用户级登录自启动，稳定副本在 %LOCALAPPDATA%\PawpalCat\app\ 下按目录版和单文件版分别保存；可在设置关闭，并尊重 Windows 手动禁用状态。单实例控制防止重复运行。

天气查询使用 Open-Meteo；CPU、GPU 温度和前台 FPS 在本机读取，Tencent Cloud 语音识别尚未接入。FPS 随包第三方许可证与来源位于 assets/vendor/presentmon/，视频解码器位于 assets/vendor/opencv-videoio/，温度依赖位于 assets/vendor/librehardwaremonitor/。看护源码位于 tools/metrics_guard.cs，确保程序异常退出后也清理自己的 ETW 会话；温度诊断日志位于设置目录的 logs/temperature.log。

## 检查与打包

```powershell
py -m unittest discover -s tests -v
py .\tools\prepare_lhm.py --verify-only
py -m pip install pyinstaller==6.22.3
py .\tools\build_windows.py
```

默认构建目录版 dist/PawpalCat-v6.3/，包含 EXE 与 _internal。可用 --output-dir 指定目录，--onefile 构建单文件版。tools/prepare_lhm.py 可从固定的官方 NuGet 包恢复依赖，--verify-only 仅校验本地文件。tools/prepare_presentmon.py 可从记录的官方来源准备 FPS 依赖并编译看护程序。构建脚本会校验视频解码 DLL 的固定哈希，只生成本地文件；如果构建用 Python 的 SSL 模块依赖证书策略资源，会一并收集，避免 EXE 中 TLS 初始化失败。

本机温度诊断（不开 GUI、不注册自启动）：

```powershell
py .\desktop_ai_pet.pyw --temperature-diagnostics .\temperature-source.json --samples 3
```

系统、动画和网络诊断（会真实解码五个随包 MP4；不读密钥、不调用收费聊天，不打开 GUI、不注册自启动；天气使用公开测试城市吉隆坡）：

```powershell
py .\desktop_ai_pet.pyw --system-diagnostics .\system-report.json
```

本轮 252 项自动化测试全部通过，其中包含随包 MP4 的真实解码、跳转、透明度、睡眠分段和托盘动作菜单检查。此前的真实源码 GUI、双托盘、天气显示与 CPU 总计数器对比结果继续保留。用户明确授权的一次 DeepSeek 官方最小聊天请求返回 HTTP 200，共使用 9 tokens；密钥未放入源码或发布包。温度硬件条件延续 v4：NVIDIA 可读，CPU 缺 PawnIO、Intel 核显无温度传感器，仍如实显示不可用。其他硬件、全新无 Python 系统和新版 Windows 任务管理器口径仍有未验证范围。
